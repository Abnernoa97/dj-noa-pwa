# Capítulo Tareas

- `ReminderWorkspace.tsx`: formularios y visualización de tareas.
- `reminderNotifications.ts`: permisos, programación y sincronización de avisos.
- `styles/`: estilos, cargados por la entrada principal en su orden original.
- `src/domains/events/eventSchedule.ts` es la lógica canónica que ancla opcionalmente tareas a horarios de eventos. Las fechas manuales se mantienen fijas.
